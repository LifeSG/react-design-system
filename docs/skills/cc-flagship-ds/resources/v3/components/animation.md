# Animation

Import: `import { Animation } from "@lifesg/react-design-system/animation"`

## Props

| Prop          | Type     | Default | Description                      |
| ------------- | -------- | ------- | -------------------------------- |
| `id`          | `string` | —       | Unique id of the component       |
| `className`   | `string` | —       | Class selector of the component  |
| `data-testid` | `string` | —       | Test identifier of the component |

### Customised variant additional props

| Prop    | Type     | Default | Description                            |
| ------- | -------- | ------- | -------------------------------------- |
| `color` | `string` | —       | Color applied on the animated elements |
