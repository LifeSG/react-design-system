# Avatar

Import: `import { Avatar } from "@lifesg/react-design-system/avatar"`

## Props

Inherits `HTMLAttributes<HTMLDivElement>`.

| Prop          | Type                      | Default     | Description                                                                         |
| ------------- | ------------------------- | ----------- | ----------------------------------------------------------------------------------- |
| `children`    | `string` \| `JSX.Element` | —           | Content displayed in the avatar — typically an initial or custom element — required |
| `sizeType`    | `"default"` \| `"small"`  | `"default"` | Size of the avatar                                                                  |
| `data-testid` | `string`                  | `"avatar"`  | Test identifier                                                                     |
