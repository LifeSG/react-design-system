# Masthead

Import: `import { Masthead } from "@lifesg/react-design-system/masthead"`

## Props

| Prop      | Type      | Default | Description                                                    |
| --------- | --------- | ------- | -------------------------------------------------------------- |
| `stretch` | `boolean` | `false` | Stretch to the maximum width of the screen, with fixed padding |

## Rules

-   No mandatory props.
-   `Masthead` is typically included via the `Navbar` `masthead` prop — use this standalone component only when rendering the masthead outside a Navbar context.
