# SingpassButton

Import: `import { SingpassButton } from "@lifesg/react-design-system/singpass-button"`

## Props

Inherits all props from `HTMLButtonElement`.

| Prop        | Type                             | Default          | Description                |
| ----------- | -------------------------------- | ---------------- | -------------------------- |
| `styleType` | `"red-filled" \| "white-filled"` | `"white-filled"` | Visual style of the button |

## Rules

-   Do not custom style — Singpass branding guidelines require using the component as-is.
