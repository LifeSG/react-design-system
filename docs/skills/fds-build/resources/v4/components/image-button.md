# ImageButton

Import: `import { ImageButton } from "@lifesg/react-design-system/image-button"`

## Props

Inherits all props from `HTMLButtonElement`.

| Prop                    | Type      | Default | Description                              |
| ----------------------- | --------- | ------- | ---------------------------------------- |
| `imgSrc`                | `string`  | —       | Image source to be rendered              |
| `selected`              | `boolean` | —       | Shows the selected state                 |
| `error`                 | `boolean` | —       | Shows the error state                    |
| `focusableWhenDisabled` | `boolean` | `false` | Keeps the button focusable when disabled |
