# CountdownTimer

Import: `import { CountdownTimer } from "@lifesg/react-design-system/countdown-timer"`

## Props

| Prop               | Type                          | Default     | Description                                                                                                                                                                              |
| ------------------ | ----------------------------- | ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `show` \*          | `boolean`                     | —           | Controls whether the timer is visible and actively counting down.                                                                                                                        |
| `fixed`            | `boolean`                     | true        | When `true`, the timer switches to a fixed viewport overlay once its inline position scrolls out of view, keeping the countdown visible at all times.                                    |
| `notifyTimer`      | `number`                      | —           | Remaining-seconds threshold at which the warning state activates. Once the countdown reaches this value, `onNotify` fires once and `onTick` fires every second until the timer finishes. |
| `offset`           | `Offset`                      | —           | Fine-tunes the fixed overlay position on tablet and desktop viewports.                                                                                                                   |
| `mobileOffset`     | `MobileOffset`                | { top: 80 } | Fine-tunes the fixed overlay position on mobile viewports.                                                                                                                               |
| `align`            | `AlignPosition`               | "right"     | Side of the inline wrapper the fixed overlay is pinned to when scrolled into sticky mode.                                                                                                |
| `onTick`           | `((seconds: number) => void)` | —           | Called every second with the remaining seconds once the countdown falls at or below `notifyTimer`.                                                                                       |
| `onNotify`         | `(() => void)`                | —           | Called once when the remaining seconds first reach the `notifyTimer` threshold.                                                                                                          |
| `onFinish`         | `(() => void)`                | —           | Called when the countdown reaches zero.                                                                                                                                                  |
| `reminderInterval` | `number`                      | 120         | Interval in seconds between polite screen-reader announcement of the remaining time while the timer is above the `notifyTimer` threshold.                                                |
| `timer` \*         | `number`                      | —           | Duration of the countdown in seconds.                                                                                                                                                    |
| `timestamp`        | `number`                      | —           | —                                                                                                                                                                                        |
