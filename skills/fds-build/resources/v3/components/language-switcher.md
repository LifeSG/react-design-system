# LanguageSwitcher

Import: `import { LanguageSwitcher } from "@lifesg/react-design-system/language-switcher"`

## Props

| Prop               | Type                                         | Default    | Description                                                                |
| ------------------ | -------------------------------------------- | ---------- | -------------------------------------------------------------------------- |
| `variant`          | `LanguageSwitcherVariant`                    | "dropdown" | Presentation mode.                                                         |
| `selectedLanguage` | `LanguageSwitcherCode`                       | "en"       | The currently active language code.                                        |
| `onSelectLanguage` | `((language: LanguageSwitcherCode) => void)` | —          | Called when the user selects a language different from `selectedLanguage`. |
