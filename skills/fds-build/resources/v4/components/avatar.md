# Avatar

Import: `import { Avatar } from "@lifesg/react-design-system/avatar"`

## Props

| Prop          | Type                    | Default | Description                                                                                                                                                                                                            |
| ------------- | ----------------------- | ------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `children` \* | `string \| JSX.Element` | —       | A string or JSX element to display inside the avatar. When a string is provided, only the first Unicode code point is rendered as an uppercase initial. Pass a JSX element (e.g. an `<img>`) to render custom content. |
| `sizeType`    | `AvatarSize`            | —       | Controls the visual size of the avatar. `"small"` renders a compact variant with reduced typography; `"default"` uses the standard size.                                                                               |
