# DateNavigator

Import: `import { DateNavigator } from "@lifesg/react-design-system/date-navigator"`

## Props

| Prop                     | Type                              | Default       | Description                                                                                                                                                                        |
| ------------------------ | --------------------------------- | ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`                     | `string`                          | —             | —                                                                                                                                                                                  |
| `className`              | `string`                          | —             | —                                                                                                                                                                                  |
| `selectedDate` \*        | `string`                          | —             | The currently displayed date in `YYYY-MM-DD` format.                                                                                                                               |
| `minDate`                | `string`                          | —             | The earliest selectable date in `YYYY-MM-DD` format. The left arrow is disabled when `selectedDate` reaches this boundary.                                                         |
| `maxDate`                | `string`                          | —             | The latest selectable date in `YYYY-MM-DD` format. The right arrow is disabled when `selectedDate` reaches this boundary.                                                          |
| `loading`                | `boolean`                         | —             | When `true`, both navigation arrows and the calendar trigger are disabled.                                                                                                         |
| `showDateAsShortForm`    | `boolean`                         | —             | When `true`, formats the displayed date using abbreviated month and day names (e.g. `"3 Jul 2025, Wed"` instead of `"3 July 2025, Wednesday"`).                                    |
| `showCurrentDateAsToday` | `boolean`                         | —             | When `true`, replaces the day-of-week label with `"Today"` if `selectedDate` matches the current calendar date.                                                                    |
| `view`                   | `"day" \| "week"`                 | "day"         | Controls whether navigation steps by a single day or by a full week. In `"week"` mode the label shows the Sunday–Saturday range that contains `selectedDate`.                      |
| `onLeftArrowClick` \*    | `(currentDate: string) => void`   | —             | Called with the current `selectedDate` value when the left arrow is clicked.                                                                                                       |
| `onRightArrowClick` \*   | `(currentDate: string) => void`   | —             | Called with the current `selectedDate` value when the right arrow is clicked.                                                                                                      |
| `onCalendarDateSelect`   | `((currentDate: string) => void)` | —             | Called with the chosen date string when the user selects a date from the calendar dropdown. When omitted the date label is non-interactive and the calendar dropdown is not shown. |
| `dropdownRootNode`       | `RefObject<HTMLElement>`          | document.body | The root element that contains the dropdown element.                                                                                                                               |
