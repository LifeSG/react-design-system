# Divider

Import: `import { Divider } from "@lifesg/react-design-system/divider"`

## Props

| Prop         | Type                   | Default          | Description                                                                                                                                                                                                                                                      |
| ------------ | ---------------------- | ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `thickness`  | `number`               | 1                | Thickness of the line in pixels.                                                                                                                                                                                                                                 |
| `lineStyle`  | `DividerLineStyleType` | "solid"          | Visual style of the line.                                                                                                                                                                                                                                        |
| `layoutType` | `DividerLayoutType`    | "flex"           | Controls how the divider is rendered relative to its parent layout. Use `"flex"` when the divider is a direct child of a flex container. Use `"grid"` to wrap the line in a `ColDiv`, enabling responsive column-span control via the `xxsCols`–`xxlCols` props. |
| `color`      | `string`               | Colour["border"] | Color of the line. Accepts a design-system colour token or any valid CSS color value.                                                                                                                                                                            |
| `xxlCols`    | `ColSpan`              | —                | Column span at the `xxl` breakpoint.                                                                                                                                                                                                                             |
| `xlCols`     | `ColSpan`              | —                | Column span at the `xl` breakpoint.                                                                                                                                                                                                                              |
| `lgCols`     | `ColSpan`              | —                | Column span at the `lg` breakpoint.                                                                                                                                                                                                                              |
| `mdCols`     | `ColSpan`              | —                | Column span at the `md` breakpoint.                                                                                                                                                                                                                              |
| `smCols`     | `ColSpan`              | —                | Column span at the `sm` breakpoint.                                                                                                                                                                                                                              |
| `xsCols`     | `ColSpan`              | —                | Column span at the `xs` breakpoint.                                                                                                                                                                                                                              |
| `xxsCols`    | `ColSpan`              | —                | Column span at the `xxs` (smallest) breakpoint. Acts as the base value. All larger breakpoints fall back to this when their own prop is not set.                                                                                                                 |
