# ImageButton

Import: `import { ImageButton } from "@lifesg/react-design-system/image-button"`

## Props

| Prop                    | Type      | Default | Description                                                                  |
| ----------------------- | --------- | ------- | ---------------------------------------------------------------------------- |
| `imgSrc` \*             | `string`  | —       | URL of the image to display inside the button.                               |
| `selected`              | `boolean` | —       | Applies a selected visual style to indicate the button is the active choice. |
| `error`                 | `boolean` | —       | Applies an error visual style to indicate a validation or selection error.   |
| `focusableWhenDisabled` | `boolean` | false   | Keeps the button reachable via keyboard focus when `disabled` is `true`.     |
