# Overlay

## Overview

Adds a dimmed layer over the application.

```tsx
import { Overlay } from "@lifesg/react-design-system/overlay";
```

<Canvas of={OverlayStories.Default} />

## Overlay click detection

If your content's visual and actual boundaries differ, clicking on the overlay
may not dismiss the overlay as expected.

A `containerRef` can be provided to define the visual container.

<Canvas of={OverlayStories.OverlayClick} />

## Scroll restoration

On iOS, the page's scroll position is locked while the overlay is open, and
restored when the last overlay closes.

If your content scrolls or navigates while the overlay is open (e.g. moving to
a new page behind a loading modal), set `disableScrollRestore` so the restore
does not override your scroll position.
